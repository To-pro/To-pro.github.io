# 非線性系統穩定性證明 via LMI

此篇將以四旋翼無人機高度控制器設計說明 PD 與 PID 控制器的差異。並且證明過程會需要用到線性矩陣不等式（Linear Matrix Inequalities, LMI）。LMI 是控制理論中常用來協助證明的重要工具。後面也將介紹如何利用 MATLAB 求解 LMI。並且還有 GUI 介面協助確認程式碼的正確性。

# 理論推導

考慮四旋翼高度動態方程式為

z¨=m−1(cos⁡ϕcos⁡θ)F−g+m−1dz\ddot{z} = m^{-1} \left( \cos \phi \cos\theta \right) F - g+ m^{-1}d_zz¨=m−1(cosϕcosθ)F−g+m−1dz​

其中zzz 為高度、mmm 為質量、ggg 為重力加速度、ϕ\phiϕ 為滾轉角、θ\thetaθ 為俯仰角和 d_z 為干擾。給定期望高度zdz_dzd​，定義追蹤誤差

ez1=z−zdez2=z˙−z˙d\begin{aligned} e_{z1} = z - z_d\\ e_{z2} = \dot{z} - \dot{z}_d \end{aligned}ez1​=z−zd​ez2​=z˙−z˙d​​

設計 PD 控制器

F=mcos⁡ϕcos⁡θ(z¨d−kpzez1−kdzez2)F = \frac{m}{\cos\phi \cos\theta} \left( \ddot{z}_d -{k}_{pz} \mathbf{e}_{z1} -{k}_{dz} \mathbf{e}_{z2} \right)F=cosϕcosθm​(z¨d​−kpz​ez1​−kdz​ez2​)

則閉迴路動態方程式為

e˙z=[01−kpz−kdz]⏟Azez+[0−g+m−1dz]⏟vz\dot{\mathbf{e}}_z = \underbrace{ \begin{bmatrix} 0 &1\\ -{k}_{pz} & -{k}_{dz} \end{bmatrix} }_{\mathbf{A}_z} \mathbf{e}_z + \underbrace{ \begin{bmatrix} 0\\ -g+ m^{-1}d_z \end{bmatrix} }_{\mathbf{v}_z}e˙z​=Az​[0−kpz​​1−kdz​​]​​ez​+vz​[0−g+m−1dz​​]​​

其中ez=[ez1ez2]T\mathbf{e}_z = \begin{bmatrix} e_{z1} & e_{z2}\end{bmatrix}^Tez​=[ez1​​ez2​​]T。閉迴路誤差動態為

e˙z=Azez+vz\dot{\mathbf{e}}_z = \mathbf{A}_z \mathbf{e}_z + \mathbf{v}_ze˙z​=Az​ez​+vz​

假設干擾滿足

∥vz∥≤vz+\| \mathbf{v}_z \| \leq v_z^+∥vz​∥≤vz+​

考慮一個 Lyapunov candidate (有時可以直接寫 Lyapunov function 因為證不出來就不會寫出來 0.0)

V=ezTPezV = \mathbf{e}_z ^T \mathbf{P} \mathbf{e}_zV=ezT​Pez​

其中P\mathbf{P}P 為對稱且正定 (P=PT>0\mathbf{P} = \mathbf{P}^T > 0P=PT>0)，並且假設一正定矩陣Q\mathbf{Q}Q 滿足Q=QT>0\mathbf{Q}=\mathbf{Q}^T>0Q=QT>0 且

PAz+AzTP≤−Q\mathbf{P}\mathbf{A}_{z}+\mathbf{A}_{z}^T\mathbf{P} \leq -\mathbf{Q}PAz​+AzT​P≤−Q

補充說明：有很複雜的數學證明由前面控制器增益的設計，可以使Az\mathbf{A}_{z}Az​ 穩定，因此有一唯一解QQQ 滿足PAz+AzTP=−Q\mathbf{P}\mathbf{A}_{z}+\mathbf{A}_{z}^T\mathbf{P} = -\mathbf{Q}PAz​+AzT​P=−Q。但我們還是會寫成不等式交給 MATLAB 求解即可。

將VVV 對時間微分得到 V˙\dot{V}V˙ 為

V˙=2ezTPe˙z=2ezTP(Azez+vz)=ezT(PAz+AzTP)ez+2ezTPvz≤−eTQe+2eTPv\begin{aligned} \dot{V} & = 2 \mathbf{e}_z^T \mathbf{P} \dot{\mathbf{e}}_z \\ & = 2 \mathbf{e}_z^T \mathbf{P} \left(\mathbf{A}_{z}\mathbf{e}_z + \mathbf{v}_z\right) \\ & = \mathbf{e}_z^T \left( \mathbf{P} \mathbf{A}_{z} +\mathbf{A}_{z}^T \mathbf{P} \right) \mathbf{e}_z + 2 \mathbf{e}_z^T \mathbf{P} \mathbf{v}_z \\ & \leq -\mathbf{e}^T \mathbf{Q} \mathbf{e} + 2 \mathbf{e}^T \mathbf{P} \mathbf{v} \end{aligned}V˙​=2ezT​Pe˙z​=2ezT​P(Az​ez​+vz​)=ezT​(PAz​+AzT​P)ez​+2ezT​Pvz​≤−eTQe+2eTPv​

根據 Cauchy-Schwarz inequality (以下範數未特別標明都為 2-norm)

∥ezTP∥≤∥ezT∥∥P∥≤λmax(P)∥ez∥\| \mathbf{e}_z^T \mathbf{P} \| \leq \| \mathbf{e}_z^T \| \| \mathbf{P} \| \leq \lambda _{max} \left( \mathbf{P}\right) \| \mathbf{e}_z \|∥ezT​P∥≤∥ezT​∥∥P∥≤λmax​(P)∥ez​∥

且根據 Rayleigh’s principle

λmin(Q)∥e∥2≤ezTQez≤λmax(Q)∥ez∥2\begin{aligned} \lambda _{min} \left( \mathbf{Q} \right) \| \mathbf{e} \| ^2 \leq \mathbf{e}_z^T \mathbf{Q} \mathbf{e}_z \leq \lambda _{max} \left( \mathbf{Q} \right) \| \mathbf{e}_z \| ^2 \end{aligned}λmin​(Q)∥e∥2≤ezT​Qez​≤λmax​(Q)∥ez​∥2​

則V˙\dot{V}V˙ 可以改寫為

V˙=−ezTQez+2ezTPvz≤−λmin(Q)∥ez∥2+2λmax(P)∥ez∥∥vz∥=−λmin(Q)∥ez∥[∥ez∥−2λmax(P)λmin(Q)∥vz∥]≤−λmin(Q)∥ez∥[∥ez∥−2λmax(P)λmin(Q)vz+]\begin{aligned} \dot{V} & = -\mathbf{e}_z^T \mathbf{Q} \mathbf{e}_z + 2 \mathbf{e}_z^T \mathbf{P} \mathbf{v}_z \\ & \leq - \lambda _{min} \left( \mathbf{Q} \right) \| \mathbf{e}_z \| ^2 +2 \lambda _{max} \left(\mathbf{P}\right) \|\mathbf{e}_z\| \|\mathbf{v}_z\| \\ & = -\lambda _{min} \left(\mathbf{Q}\right) \|\mathbf{e}_z\| \left[ \| \mathbf{e}_z \| - \frac{2\lambda _{max}\left(\mathbf{P}\right)}{\lambda _{min} \left( \mathbf{Q}\right)}\|\mathbf{v}_z\|\right] \\ & \leq -\lambda _{min} \left(\mathbf{Q}\right) \|\mathbf{e}_z\| \left[ \| \mathbf{e}_z \| - \frac{2\lambda _{max}\left(\mathbf{P}\right)}{\lambda _{min} \left( \mathbf{Q}\right)} v_z^+ \right] \end{aligned}V˙​=−ezT​Qez​+2ezT​Pvz​≤−λmin​(Q)∥ez​∥2+2λmax​(P)∥ez​∥∥vz​∥=−λmin​(Q)∥ez​∥[∥ez​∥−λmin​(Q)2λmax​(P)​∥vz​∥]≤−λmin​(Q)∥ez​∥[∥ez​∥−λmin​(Q)2λmax​(P)​vz+​]​

令

ε=2λmax(P)λmin(Q)vz+\varepsilon = 2 \frac{\lambda _{max}\left(\mathbf{P}\right)}{\lambda _{min} \left( \mathbf{Q}\right)} v_z^+ε=2λmin​(Q)λmax​(P)​vz+​

當 ∥ez∥>ε\|\mathbf{e}_z\| > \varepsilon∥ez​∥>ε 則 V˙<0\dot{V} < 0V˙<0 誤差系統為漸近穩定。

# 增加積分器

同樣不補償重力加速度，設計 PID 控制律為

F=mcos⁡ϕcos⁡θ(z¨d−kpzez1−kiz∫0tez1(τ)dτ−kdzez2)F = \frac{m}{\cos\phi \cos\theta} \left( \ddot{z}_d -{k}_{pz} \mathbf{e}_{z1} -{k}_{iz} \int_0^t\mathbf{e}_{z1}(\tau)d\tau -{k}_{dz} \mathbf{e}_{z2} \right)F=cosϕcosθm​(z¨d​−kpz​ez1​−kiz​∫0t​ez1​(τ)dτ−kdz​ez2​)

閉迴路誤差動態為

e˙z1=ez2e˙z2=−kpzez1−kiz∫0tez1(τ)dτ−kdzez2−g+m−1dz\begin{aligned} \dot{e}_{z1} &= \mathbf{e}_{z2}\\ \dot{e}_{z2} &= -{k}_{pz} \mathbf{e}_{z1} -{k}_{iz} \int_0^t\mathbf{e}_{z1}(\tau)d\tau -{k}_{dz} \mathbf{e}_{z2} -g+ m^{-1}d_z \end{aligned}e˙z1​e˙z2​​=ez2​=−kpz​ez1​−kiz​∫0t​ez1​(τ)dτ−kdz​ez2​−g+m−1dz​​

定義擴增狀態

ez0=∫0tez1(τ)dτ−kiz−1g+kiz−1m−1dz⇒e˙z0=ez1+kiz−1m−1d˙ze_{z0} =\int_0^t\mathbf{e}_{z1}(\tau)d\tau -k_{iz}^{-1}g+ k_{iz}^{-1}m^{-1}d_z \Rightarrow \dot{e}_{z0} =\mathbf{e}_{z1} +k_{iz}^{-1}m^{-1}\dot{d}_zez0​=∫0t​ez1​(τ)dτ−kiz−1​g+kiz−1​m−1dz​⇒e˙z0​=ez1​+kiz−1​m−1d˙z​

則誤差動態可以改寫為

e˙z0=ez1+kiz−1m−1d˙ze˙z1=ez2e˙z2=−kizez0−kpzez1−kdzez2\begin{aligned} \dot{e}_{z0} &=\mathbf{e}_{z1}+k_{iz}^{-1}m^{-1}\dot{d}_z\\ \dot{e}_{z1} &= \mathbf{e}_{z2}\\ \dot{e}_{z2} &= -{k}_{iz} \mathbf{e}_{z0} -{k}_{pz} \mathbf{e}_{z1} -{k}_{dz} \mathbf{e}_{z2} \end{aligned}e˙z0​e˙z1​e˙z2​​=ez1​+kiz−1​m−1d˙z​=ez2​=−kiz​ez0​−kpz​ez1​−kdz​ez2​​

以矩陣形式表達為

e˙z=[010001−kiz−kpz−kdz]⏟Azez+[−kiz−1m−1d˙z00]⏟vz\dot{\mathbf{e}}_z = \underbrace{ \begin{bmatrix} 0 &1 &0\\ 0 &0 &1\\ -{k}_{iz} &-{k}_{pz} & -{k}_{dz} \end{bmatrix} }_{\mathbf{A}_z} \mathbf{e}_z + \underbrace{ \begin{bmatrix} -{k}_{iz}^{-1}m^{-1}\dot{d}_z\\ 0\\ 0 \end{bmatrix} }_{\mathbf{v}_z}e˙z​=Az​⎣⎢⎡​00−kiz​​10−kpz​​01−kdz​​⎦⎥⎤​​​ez​+vz​⎣⎢⎡​−kiz−1​m−1d˙z​00​⎦⎥⎤​​​

其中ez=[ez0ez1ez2]T\mathbf{e}_z = \begin{bmatrix} e_{z0} & e_{z1} & e_{z2}\end{bmatrix}^Tez​=[ez0​​ez1​​ez2​​]T。

警告：這裡要先說一篇文章中變數不能混用，但因為方便說明 PD 與 PID 的差異因此這裡用成類似的形式方便比較。

觀察改用 PID 控制器的誤差動態干擾項vz\mathbf{v}_zvz​。沒有了重力項 (可以看成模型不確定性)，原本的干擾dzd_zdz​ 也變成一次微分，並且還除上積分增益。因此若是常數干擾或是慢時變函數控制器只要有積分器就可以解決。證明的過程是一樣的因此跳過。

# MATLAB 解 LMI

剛剛是穩定性證明，接著這邊是要說明如何用 MATLAB 解 LMI。前一節的證明是基於有一
P\mathbf{P}P 為對稱且正定 (P=PT>0\mathbf{P} = \mathbf{P}^T > 0P=PT>0) 和一對稱且正定矩陣Q\mathbf{Q}Q(Q=QT>0\mathbf{Q}=\mathbf{Q}^T>0Q=QT>0) 滿足

PAz+AzTP≤−Q\mathbf{P}\mathbf{A}_{z}+\mathbf{A}_{z}^T\mathbf{P} \leq -\mathbf{Q}PAz​+AzT​P≤−Q

才有 Lyapunov function 所保證的穩定。因此我們現在要找出對應的P\mathbf{P}P 和Q\mathbf{Q}Q。

# MATLAB 圖形化介面

MATLAB lmiedit 是一個 MATLAB 內建解 LMI 的 GUI 介面。好處是可以可視化 LMI。缺點是急需優化、超容易崩潰等問題 (根本還是測試用功能吧？)。提醒請按照步驟做不然我也不知道他很容易跳 error。

  • 在 MATLAB 的 Command Window 輸入 lmiedit 就會跳出 GUI 介面。上下都點選 view commands

  • 在上半部輸入變數 (需要 LMI 初始化的程式碼)

建議不要有多餘的註解或空行。它很脆弱的。

  • 在下半部輸入 LMI 的描述和最後的求解 LMI

  • 最後按左下的 describe LMIS as MATLAB expressions 即可看到數學式。檢查是否跟期望的相同。一樣就趕快把這爛視窗關掉
