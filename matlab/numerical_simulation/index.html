# 數值模擬

在工數有學過怎麼解微分方程，但現實中我們需要處理的動態無法輕易的計算出解析解。因此就可以用數值模擬的方式計算出結果。一個淺顯易懂的求解方式就是 Euler Method。如果一個動態可以描述為

y˙(t)=f(y(t),t)\dot{y}(t) = f(y(t),t)y˙​(t)=f(y(t),t)

則 Euler Method 就是利用斜率去推算下一刻的yyy 也就是

y(t+△t)=y(t)+△tf(y(t),t)y(t+\triangle t) = y(t) + \triangle t f(y(t),t)y(t+△t)=y(t)+△tf(y(t),t)

當然這樣模擬的結果與真實的結果會有差異，因此這裡可以調整間隔△t\triangle t△t 或是使用其他更適合的求解器求解。

了解什麼是數值模擬後直接進入主題介紹 MATLAB 中常用的數值模擬函數:

  • lsim: 模擬線性系統的響應。

  • ode45: 模擬非線性系統的響應。當然線性系統也可以模擬。此函數為變步長求解器 (也就是時間間隔不固定，輸出等間隔是使用內插)，因此可以透過設定提高模擬精度。

  • RK4: 自己打的程式，好處是可以撈自己想要的資料。求解方式全名為 Runge-Kutta 4th，是一種定步長的數值模擬。要調高模擬精度只能縮短時間間隔。學理部分參考維基或自行網路搜尋就偷懶不寫了。

# 模擬系統推導：標準一階系統 (prototype first order system)

系統函數為

G(s)=1TsG(s) = \frac{1}{Ts}G(s)=Ts1​

其中TTT 為時間常數。則單位負回授的轉移函數為

Y(s)R(S)=1Ts+1T\frac{Y(s)}{R(S)} = \frac{\frac{1}{T}}{s + \frac{1}{T}}R(S)Y(s)​=s+T1​T1​​

整理得到

R(S)=TY(s)s+Y(s)R(S) = T Y(s) s + Y(s)R(S)=TY(s)s+Y(s)

逆轉換得到

r(t)=Ty˙(t)+y(t)r(t) = T \dot{y}(t) + y(t)r(t)=Ty˙​(t)+y(t)

整理得到輸出 (yyy) 與輸入 (rrr) 的一階微分方程關係為

y˙(t)=−1Ty(t)+1Tr(t)\dot{y}(t) = - \frac{1}{T} y(t) + \frac{1}{T}r(t)y˙​(t)=−T1​y(t)+T1​r(t)

若輸入為單位步階訊號則可以透過轉移函數計算輸出為

Y(s)=1Ts+1T1s=1s−1s+1TY(s) = \frac{\frac{1}{T}}{s + \frac{1}{T}}\frac{1}{s} = \frac{1}{s} - \frac{1}{s + \frac{1}{T}}Y(s)=s+T1​T1​​s1​=s1​−s+T1​1​

inverse laplace 得到解析解的輸出為

y(t)=1−e−1Tty(t) = 1 - e^{-\frac{1}{T}t}y(t)=1−e−T1​t

x1=xx2=x˙x_1 = x \quad x_2 = \dot{x}x1​=xx2​=x˙
