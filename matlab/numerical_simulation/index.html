# 數值模擬

在工數有學過怎麼解微分方程，但現實中我們需要處理的動態無法輕易的計算出解析解。因此就可以用數值模擬的方式計算出結果。一個淺顯易懂的求解方式就是 Euler Method。如果一個動態可以描述為

y˙(t)=f(y(t),t)\dot{y}(t) = f(y(t),t)y˙​(t)=f(y(t),t)

則 Euler Method 就是利用斜率去推算下一刻的yyy 也就是

y(t+△t)=y(t)+△tf(y(t),t)y(t+\triangle t) = y(t) + \triangle t f(y(t),t)y(t+△t)=y(t)+△tf(y(t),t)

當然這樣模擬的結果與真實的結果會有差異，因此這裡可以調整間隔△t\triangle t△t 或是使用其他更適合的求解器求解。

了解什麼是數值模擬後直接進入主題介紹 MATLAB 中常用的數值模擬函數:

  • lsim: 模擬線性系統的響應。

  • ode45: 模擬非線性系統的響應。當然線性系統也可以模擬。此函數為變步長求解器 (也就是時間間隔步固定，輸出等間隔是使用內插)，因此可以透過設定提高模擬精度。

  • RK4: 自己打的程式，好處是可以撈自己想要的資料。求解方式全名為 Runge-Kutta 4th，是一種定步長的數值模擬。要調高模擬精度只能縮短時間間隔。學理部分參考維基或自行網路搜尋就偷懶不寫了。
