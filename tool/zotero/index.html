# Zotero

Zotero 是一款自由及開放原始碼的文獻管理軟體，用以管理書目資訊（如作者、標題、出版社、摘要、閱讀筆記等）及相關材料（如 PDF 檔案）。其最著名的特性是作為瀏覽器外掛程式、線上同步、與文件編輯軟體如 Microsoft Word、LibreOffice、OpenOffice.org Writer、NeoOffice 等整合，可生成文內參照（英語：citation）、生成頁面註腳或文後的參考文獻（bibliographies）。(此段介紹來源於 wiki)

網上已有許多教學資料:ZOTERO+TeraCloud 跨平台文献管理教程

# TeraCloud

選擇 TeraCloud 有兩點重要原因，第一是支持 WebDav，第二提供 10GB (+7 好友碼) 免費存儲空間。使各設備上的文獻可以同步。

# 安裝插件

主要有三種插件 zotfile (參考)、Zotero Connector 和 Better BibTex

# zotfile

插件是用於將 zotero 中文獻附件轉移至網絡同步盤中的一種插件，可以解決官方同步空間小的問題。

# Zotero Connector

可以將網頁查到的東東快速加進書庫中

# Zotero Better BibTex

方便引用，後面設定教學參考這裡。這邊要特別注意不同設備的插件設定不會同步。所以筆電、桌機等都會要引用文獻時就要注意插件設定是否相同，也因此這裏特別對此插件寫個筆記。另外因為 zotero 改版了，所以 GUI 介面會與接下來的示範有些微不同。但要注意與設定的地方是相同的有時間再更新惹。

# 如何在 latex 中用 Zotero 引用參考文獻？

betterbibtex 官網
官網可以點選右邊菜單的 Download 到 github 下載 .xpi 檔

接著在 Zotero 點選 Tool -> Add-ons

然後新的視窗中點選 設定 (右上小齒輪) -> Install Add-ons From File -> 選擇剛剛下載的 .xpi 檔 -> 新視窗使否信任選擇 Install

裝好後如下圖所示，需重新起動

接下來是建議設定:
Edit -> Preference -> Better BibTeX -> Open Better BibteX preference
首先是 Citation key 中 Citation key formula

auth.lower + shorttitle(1,1) + year

將 latex 中要 cite 時的名稱為 作者姓氏 + 論文標題第一個字 + 年份

在 Export -> Fields -> Fields to omit from export (comma-separated) 中輸入 abstract,note,file,keyword

這是設定匯出至.bib 檔案時不包含摘要、註解、關鍵字、附件目錄等不必要的資訊。

接著是在 Export -> Miscellaneous 取消勾選預設的 Apply case-protection to capitalized words by enclosing them in braces (標題關鍵字全部大寫的設定)。
這一項如果不取消勾選，導出的.bib 檔案中，title 的某些字會被花括號包裹，如此，會導致 /printbibliography 時，英文標題中的單字全部大寫。 例如：{Trade} Value 會變成 TRADE Value，這在大多數情況下是不符合參考文獻規範的。 此選項具體可參考 Better BibTex FAQ。
參考網站

然後按 OK 就設定好 Bbetterbibtexetter 啦！
還要在 Zotero 中 Edit -> Preference -> Eeport -> Item Format -> 選擇 Better BibLaTex 即可

  • 選擇欲引用之文獻 (可多選) ctrl+shift+C 複製後直接貼上即可

  • 若欲複製文末參考文獻 ctrl+shift+C 或點選編輯→複製參考文獻條

記得新加入的文獻或是一開始要在 My Library 全選文獻 (Ctrl + a) -> 右鍵選單選擇 -> Better BibTex -> Refresh BibTex key (Better BibTex 插件才會更新你 bib 的引入格式)

如此選取文獻 (單或複數) 用 Ctrl Shift C 就可以複製 .bib 的格式了。如下所示

@article{pengRobust2011,
  title = {A Robust Integral Type Backstepping Controller Design for Control of Uncertain Nonlinear Systems Subject to Disturbance},
  author = {Peng, Chao-Chung and Li, Yun-Ze and Chen, Chieh-Li},
  date = {2011-05-01},
  journaltitle = {International Journal of Innovative Computing, Information and Control},
  shortjournal = {International Journal of Innovative Computing, Information and Control},
  volume = {7}
}
